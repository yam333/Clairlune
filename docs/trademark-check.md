# Trademark check: "Clairlune"

Checked 2026-11-19 (PLAN.md section 15.2.1). This is a search record, not legal advice.

## Method

| Register | Tool | Queries |
|---|---|---|
| USPTO (United States) | tmsearch.uspto.gov search backend, word mark + pseudo-mark fields | `clairlune`, `clair*lune*`, `lune AND clair`, sound-alikes `clerlune`, `clairlun`, `klairlune`, `clarelune`, `clairlunes` |
| EUIPO (European Union) and national offices | TMview (tmdn.org), which covers EUIPO, the US, UK, the EU national offices, WIPO and many others | exact `clairlune` (EUIPO only, then all offices), fuzzy `clairlune` (all offices), `clair de lune` (EUIPO) |

Positive controls confirmed both searches work: USPTO returns CLAIRDELUNE (reg. 5451847, live, class 18), and TMview returns the same US mark plus 11 EUIPO "Clair de Lune" marks.

A web search also found no app, software product or company called Clairlune.

## Assessment

- No conflict found for software in the US or the EU. The name can be used for the release.
- The Chinese CLAIRLUNE registrations cover unrelated goods (clothing, household items, retail). They don't block software use, but they would matter if the project ever sold merchandise under the name in China.
- "Clair de Lune" marks are many, but they are a different, longer phrase used for consumer goods, and none is live in classes 9 or 42.
- Optional later step: file a US or EU application in classes 9 and 42 if the project grows. Not needed for an open-source release.

## Re-check

Repeat this search before any store listing or paid release, since new applications appear continually.
