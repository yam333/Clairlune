# Code of conduct

Clairlune follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and assume good faith. Harassment, personal attacks,
discriminatory language and publishing other people's private information are
not acceptable in issues, pull requests or anywhere else in the project.

To report something, mention the maintainer, @yam333, on the issue or pull
request concerned. If it shouldn't be public, open a short issue asking for a
private channel, without the details. Reports are handled in confidence. The
maintainer may edit or remove comments, and block people who break these
rules.
