01 / Desktop Wallpaper Engine Windows 10/11 · macOS 13+ · Linux CLI

Native Rust · Seeded & Deterministic · MIT / Apache-2.0

Landscapes drawn in type, alive behind your desktop.

Clairlune renders scenes locally from a seed into crisp text glyphs, live weather, and an optional pixel-art Clawd behind your desktop icons. There is no telemetry; only the optional daily update check uses the network.

Download Windows setup.exe All Windows files & SHA256 
scoop bucket add clairlune https://github.com/yam333/homebrew-clairlune
scoop install clairlune

Per-user installer for Windows 10 and 11; requires no administrator privileges.

curl -fsSL https://raw.githubusercontent.com/yam333/Clairlune/main/install.sh | sh
brew install --cask yam333/clairlune/clairlune

macOS 13+ (Apple Silicon & Intel DMGs on Releases; see the Gatekeeper first-open note). 

cargo install clairlune       # desktop app (Windows & macOS, Rust 1.95+)
cargo install clairlune-cli   # headless CLI (Windows, macOS & Linux, Rust 1.90+)

On Linux, clairlune-cli renders identical PNG stills, looping GIFs, and scene packages.

Campfire · Mountains · LIVE Clairlune 22:14

02 / Engineering Properties Deterministic Pixel Pipeline
01 / DETERMINISM

Byte-identical across CPUs

Glyphs rasterize from skrifa outlines using integer coverage and libm math. Seed 7 produces the exact same PNG bytes on Windows x64, Apple Silicon, and Linux.

02 / LIVE PLAYBACK

Dirty-tile desktop presenter

Live mode copies only the small grid cells where embers, snow, or water moved, and pauses automatically behind full-screen windows, while locked, or on battery.

03 / MULTI-MONITOR

Per-display or spanned horizon

Give every monitor its own native-resolution scene and content rules, or align displays visually to span one continuous landscape across bezels and Retina scales.

04 / QUIET FOOTPRINT

Zero resident UI memory

Closing Settings drops the wgpu surface and device completely so the tray process idles cleanly. Configuration lives in plain, human-editable TOML files.

06 / Headless CLI & Workspace 7 Rust Crates · Zero-I/O Core

Scriptable from the terminal.

clairlune-cli uses the same scene and render crates without loading any GUI toolkit, on Windows, macOS, and Linux. This one runs them in your browser: type a command.

clairlune-cli · in your browser Full CLI reference 
# 4K indexed PNG from a deterministic seed
clairlune-cli generate --seed 7 --theme dark --size 3840x2160 --out wallpaper.png

# Seamless looping GIF for sharing
clairlune-cli gif --seed 7 --activity warm_hands --size 960x540 --out fire.gif

# Freeze a scene package (~0.5-1 MB at 4K) immune to generator updates
clairlune-cli package --seed 7 --size 1920x1080 --out scene7

# Render a multi-seed contact sheet to inspect variety
clairlune-cli contact-sheet --archetype shore --count 12 --out shores.png
$

07 / Questions From the user guide

Before you install.

The questions people ask first. Everything else is in the user guide.

01What is Clairlune?

A desktop app for Windows and macOS that puts a new landscape drawn in text characters on your wallpaper every hour, with Clawd doing something in it. Every scene comes from a seed, so the same seed always draws the same picture. It has nothing to do with Debussy's Clair de lune.

02Is Clairlune free?

Yes. It is free and open source under MIT or Apache-2.0, with no account, ads or purchases.

03Will it slow my computer down?

Live redraws only the parts of the scene that change. It pauses while an app fills the screen (maximized, zoomed or full screen), while the computer is locked, and on battery if you ask it to. Still frame sets one picture and costs nothing between changes; Settings > Live > Smoothness lowers the frame rate.

04Does Clairlune collect any data?

No. Every wallpaper is made on your computer, and Clairlune sends nothing about you anywhere. It goes online only to ask GitHub for the newest version (once a day unless you change it in Settings) and to download an update when you click Update now.

05Does it work with more than one monitor?

Yes. Each monitor gets its own scene at its own resolution, or one wide scene spreads across all of them (Settings > Display > Monitors).

06Does Clairlune run on Linux?

The desktop app is for Windows 10 and 11 and macOS 13 or later. On Linux, clairlune-cli renders the same scenes as PNG stills and GIFs (CLI reference).

07macOS says Clairlune can't be opened. What do I do?

Click Done (not Move to Trash), then Open Anyway at the bottom of System Settings > Privacy & Security, once. If there's no Open Anyway, or it says the app is damaged, install with the one-line Terminal installer instead (step by step).

08How do I get a wallpaper back?

Copy its seed in Settings and type it into Settings > Rotation > From a seed. A wallpaper still in the archive (the last week) or the library comes back exactly as it was.
